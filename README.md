# Pizza Sales Analysis Dashboard

## Project Overview

This project analyzes pizza sales data using Power BI to understand revenue performance, order activity, product performance, customer ordering patterns, and sales trends.

## Business Problem

The objective was to create an interactive dashboard that helps users understand key sales KPIs, identify high-performing products, analyze order trends, and evaluate pizza category and size performance.

## Tools Used

- Power BI
- Power Query
- DAX
- Excel
- Data Cleaning
- Data Visualization

## Data Cleaning & Preparation

- Checked the dataset for missing and inconsistent values.
- Verified date, quantity, price, and categorical fields.
- Prepared and transformed the data using Power Query.
- Organized pizza categories and sizes for reporting.
- Created and validated measures required for KPI reporting.

## Key KPIs

- Total Revenue: 817.86K
- Average Order Value: 38.31
- Total Pizzas Sold: 49,574
- Total Orders: 21,350
- Average Pizzas per Order: 2.32

## Analysis Areas

- Daily Order Trends
- Monthly Order Trends
- Sales by Pizza Category
- Sales by Pizza Size
- Product Performance
- Best and Worst Sellers
- Customer Ordering Patterns

## Key Insights

- Friday shows the highest order volume in the daily trend analysis.
- July records the highest monthly order volume in the dashboard.
- Classic pizzas contribute the largest share of category sales.
- Large pizzas contribute the largest share of sales by size.
- Classic pizzas have the highest number of pizzas sold among the displayed categories.
- Weekend and evening periods show relatively stronger order activity.

## Business Recommendations

- Maintain sufficient staffing and inventory during peak periods.
- Prioritize high-performing categories and popular pizza sizes.
- Investigate lower-performing products for possible pricing or promotional improvements.
- Use monthly sales trends to support demand planning.
- Explore bundle and upselling opportunities to improve average order value.
